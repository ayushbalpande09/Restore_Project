# ReStore 🌿

**ReStore** is a modern thrift store and pre-loved clothing platform designed to promote sustainable fashion. It provides a clean, user-friendly space to browse, buy, and list gently used (one-time worn) outfits, giving quality fashion a second life while reducing textile waste.

---

## ✨ Features

* **Curated Thrift Catalog:** Browse pre-loved and one-time used clothing with clear pricing and condition details.
* **List Your Outfit:** Interactive form allowing users to easily submit their own gently used garments for resale or sharing.
* **Interactive Mobile Prototype:** Embedded 3-screen Figma prototype (**Home**, **Details**, and **Bag**) demonstrating the mobile shopping flow.
* **Responsive Design:** Built with Bootstrap 5 to adapt smoothly across desktop, tablet, and mobile screens.
* **Eco-Friendly Aesthetic:** Minimalist, earthy UI styled with a Forest Green (`#1F4E3D`) and Cream (`#F8F6F2`) color palette.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **UI/UX & Prototyping:** Figma
